# Localization notes

This directory holds the per-language content files for the website.

- `en.ts` — English (default, implemented)
- `uk.ts`, `fr.ts`, `de.ts`, `es.ts` — reserved for future translations

Only English is implemented at this stage. Other languages are intentionally
not exposed as functional language versions yet. Future translations will be
added here following the `LocaleContent` type defined in `../types.ts`.
